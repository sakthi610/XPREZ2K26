# XPREZ — Images Directory
# ============================
# Place all website images here, organized in subdirectories.
#
# Recommended structure:
#
# /images
# │── /articles/           — Article featured images
# │   └── article-slug.jpg
# │
# │── /magazine/           — Magazine cover images
# │   └── xprez-2025-cover.jpg
# │   └── xprez-2025-thumb.jpg
# │
# │── /gallery/            — Gallery photographs
# │   └── event-name-001.jpg
# │
# │── /team/               — Team member headshots
# │   └── member-name.jpg
# │
# │── /og/                 — Open Graph / social share images
# │   └── og-default.jpg  (1200×630px recommended)
# │
# │── logo.png             — XPREZ logo file
# │── favicon.ico          — Website favicon
# └── favicon.png          — Favicon PNG (32×32)
#
# Image Format Guidelines:
# - Use WebP for best compression with JPEG fallback
# - Article/gallery images: 800×600 minimum, optimized < 200KB
# - Magazine covers: 600×800 (portrait), optimized < 300KB
# - Team photos: 400×400 (square), optimized < 100KB
# - OG images: 1200×630px
#
# Tools for optimization:
# - Squoosh (https://squoosh.app)
# - TinyPNG (https://tinypng.com)
# - ImageOptim (Mac)
