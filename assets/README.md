# XPREZ — Assets Directory
# ============================
# Place static assets (fonts, icons, documents, etc.) here.
#
# Recommended structure:
#
# /assets
# │── /fonts/              — Self-hosted fonts (if not using Google Fonts CDN)
# │   └── Inter-Regular.woff2
# │   └── PlayfairDisplay-Bold.woff2
# │
# │── /icons/              — SVG icon files
# │   └── icon-name.svg
# │
# │── /pdfs/               — Magazine PDF files
# │   └── xprez-annual-2025.pdf
# │   └── xprez-annual-2024.pdf
# │
# │── /downloads/          — Any other downloadable content
# └── README.md
#
# PDF Upload Guidelines:
# - Compress PDFs before uploading (target < 5MB per issue)
# - Name format: xprez-annual-YYYY.pdf
# - Tools: Smallpdf, iLovePDF, Adobe Acrobat
#
# Future: PDFs may be hosted on a CDN (e.g., AWS S3, Cloudinary)
# for better performance and download speeds.
